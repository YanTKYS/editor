# UI/UX 改善案と対応状況

利用方法は [README](../README.md)、実装の詳細やバージョンごとの変更は [変更履歴](../CHANGELOG.md) を参照してください。提案の ID は維持し、対応状況を以下の4区分で整理します。提案の優先度は目安で、採用や公開時期は未定です。

## 実装・リリース済

以下は v0.4.0 に収録済みです。

| ID | 内容 |
| --- | --- |
| UX-01 | ブラウザ内の自動保存と、ファイル未書き出し状態を区別する。 |
| UX-02 | 検索・置換が現在のタブと全タブのどちらを対象にするか明示する。 |
| UX-03 | 操作対象のペイン・ファイル名と、タブの表示先を分かりやすくする。 |
| UX-06 | 差分比較の比較元・比較先を入れ替え、不正なペイン指定を選択時に示す。 |
| UX-09 | 差分比較のメニュー説明を、比較元・比較先・結果の3ペイン方式に揃える。 |
| UX-10 | 全タブ検索結果が古くなったことを示し、再検索で更新する。 |

## 実装済・未リリース

| ID | 内容 |
| --- | --- |
| UX-07 | 全タブ置換の確定前に、ファイルごとの位置と変更前後を表示する。表示の省略を明示し、確認後に本文・条件・タブ構成が変わった場合は実行を止める。 |
| UX-13 | 未書き出しタブを選んで通常のファイルを ZIP へ書き出す。同名・改行・BOM に対応し、保存確認後に変更のないタブだけ状態を更新する。 |
| UX-15 | 全タブ置換の対象をタブごとに選択・除外する。件数とプレビューを更新し、同名タブ・対象なし・多数のタブに対応する。選択外の本文は維持する。 |

## 提案事項

| ID | 優先度 | 提案 | 改善内容・期待する効果 | 検討時の留意点 |
| --- | --- | --- | --- | --- |
| UX-04 | 中 | コマンドパレット | 「折り返し」「差分」などの機能を日本語で検索・実行し、メニューを探す負担を減らす。 | 既存メニューと処理を共通化し、キーボードで実行・中止できること。UX-11 と検索入口の役割を整理する。 |
| UX-05 | 中 | 狭い画面での主要操作への到達性 | 幅480px以下でも「開く・書き出し・検索」に到達しやすくし、小さい `×` や `▾` のクリック領域を広げる。 | 本文の表示領域を保ち、幅375px・拡大表示・キーボードで確認する。実装済みの操作対象表示とは別の改善として扱う。 |
| UX-08 | 低 | 全タブ置換をまとめて元に戻す | 現状のタブごとの Undo に加え、一括置換をまとめて取り消せるようにする。 | 置換後の編集、タブの閉鎖・再オープン、各タブの Undo/Redo と整合させる。 |
| UX-11 | 中 | タブ一覧の名前による絞り込み | 多数のタブから名前の一部で探し、表示先ペインも確認して移動できるようにする。 | 日本語の入力確定中に誤実行せず、同名・長い名前・一致なしを扱えること。中止後のフォーカスも維持する。 |
| UX-12 | 低 | 分割ペインの幅調整 | 等幅を既定に保ち、長い文書や差分結果へ必要な幅を割り当てる。 | 編集ペイン同士の調整が対象。キーボード操作、最小幅、等幅への復帰、分割数変更・比較終了時の復元と保存を設計する。 |
| UX-14 | 低 | 差分結果のテキスト書き出し | 一時表示の差分をファイルとして取得し、共有・記録しやすくする。 | 比較の向きと出力時点を明確にし、元のタブは変更しない。差分なし・簡易比較を扱い、パッチ適用への対応は別途判断する。 |
