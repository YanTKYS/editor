# UI/UX 改善案と対応状況

## この文書の位置付け

v0.4.0 と未リリースの実装を基準に、完了した提案と今後の候補を整理する。既存の ID は維持する。優先度は候補同士を比較するための目安であり、次のリリースへの採用や実装時期を約束するものではない。

現行の利用方法は [README](../README.md)、バージョンごとの変更は [変更履歴](../CHANGELOG.md) を参照する。本書は開発候補の管理に使い、過去の変更履歴は書き換えない。

提案はコードの読み取りに基づく。ユーザーテストによる効果検証は未実施。

## 次回の検討順序

次のリリース番号・範囲は未定。UI に常設する情報や操作は必要最小限とし、候補をすべて一度に採用しない。

| 順序 | 対象 | 理由 |
| --- | --- | --- |
| 利用頻度を確認して選定 | UX-05・UX-07 | 狭い画面での到達性、変更前の確認を改善する。 |
| タブ数・機能数の増加に合わせて検討 | UX-04・UX-11 | 操作やタブを探す負担を減らす。二つの検索入口の役割も整理する。 |
| 設計・需要の確認後に判断 | UX-08・UX-12 | 編集履歴やペイン配置への影響が大きいため、挙動を先に決める。 |
