# Web Text Editor

ブラウザで動作する、日本語 UI のタブ型テキストエディタです。CodeMirror 6 を使用し、日常の文書編集やファイルの比較に利用できます。

最新の公開版は [v0.5.0](https://github.com/YanTKYS/editor/releases/tag/v0.5.0) です。この README は main のソースを基準にしており、版ごとの収録内容は [変更履歴](CHANGELOG.md) で確認できます。

## 特徴・動作環境

- 複数タブ、タブごとの Undo/Redo、構文ハイライト、Markdown プレビュー
- 全タブ検索・置換プレビューと対象選択、1〜4分割、3ペインでの差分比較
- UTF-8 / Shift_JIS の読み込み、UTF-8 での書き出し、一括 ZIP 書き出し、差分テキストの出力
- 静的ファイルだけで動作し、実行時の外部 API・CDN は不要。編集内容はサーバーへ送信しません
- 対応ブラウザは Chrome / Edge の最新版。閉域環境の静的 HTTP サーバーにも配置できます

## 利用を始める

1. [GitHub Pages](https://yantkys.github.io/editor/) を開くか、[Releases](https://github.com/YanTKYS/editor/releases) の ZIP を取得して [静的 HTTP サーバーで起動](docs/deployment.md#配布-zip-をローカルで確認する) します。ZIP 内の index.html をダブルクリックする `file://` 方式では動作しません。
2. 「開く」（`Ctrl+O`）またはドラッグ＆ドロップでファイルを開き、編集します。新規タブは `Alt+N` でも作成できます。
3. 「ファイルに書き出し」（`Ctrl+Shift+S`）で PC にファイルを保存します。検索・置換は `Ctrl+F` / `Ctrl+H`、操作キーの一覧は「ヘルプ」で確認できます。

**ブラウザ内の自動保存と、PC へのファイル書き出しは別です。** `Ctrl+S` はこのブラウザへの保存です。タブの `●` はファイル未書き出しの変更を示します。ブラウザのデータ削除や保存容量超過に備え、重要な内容はファイルまたはバックアップ JSON に書き出してください。

ZIP 一括書き出しと「書き出してから閉じる」は、保存できたことを確認してから「保存を確認した」を選びます。保存を中止した場合は未書き出しのまま戻ってください。
