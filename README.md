# Web Text Editor

ブラウザだけで動作する、タブ形式のテキストエディタです（v0.4.0）。変更履歴は [CHANGELOG.md](CHANGELOG.md) を参照してください。
エディタエンジンに [CodeMirror 6](https://codemirror.net/) を使用し、Notepad++ のような日常的なテキスト編集を想定しています。

この README は `main` ブランチのソースを基準にしています。公開済み v0.4.0 の内容と、以降の [未リリースの変更](CHANGELOG.md#未リリース) は変更履歴で区別しています。配布済み ZIP のバージョンと内容は [Releases](https://github.com/YanTKYS/editor/releases) と該当バージョンの変更履歴を確認してください。

- サーバー処理・外部 API・実行時の CDN 読み込みは一切ありません（静的ファイルのみで動作）
- 編集内容はブラウザ内（localStorage）に自動保存され、外部へ送信されません
- 対応ブラウザ: Chrome / Edge の最新版

## 使い方

| 操作 | 方法 |
|---|---|
| 新規タブ | `Ctrl+N`（ブラウザが優先する場合は `Alt+N`）、タブバーの `+`、タブバー余白のダブルクリック |
| ファイルを開く | `Ctrl+O`、またはファイルを画面にドラッグ＆ドロップ（複数可） |
| Shift_JIS のファイルを開く | 「ファイル」→「Shift_JIS のファイルを開く…」。UTF-8 として読めないファイルは開くときに確認します |
| ブラウザ内に保存 | 自動保存されます。`Ctrl+S` で即時保存 |
| 未書き出しタブの一括書き出し（未リリース） | 「ファイル」→「未書き出しタブをまとめて書き出し…」。対象を選んで ZIP を取得 |
| ファイルに書き出し（ダウンロード） | `Ctrl+Shift+S`。「名前を付けて書き出し…」でファイル名を指定 |
| タブ名の変更 | `F2`、タブのダブルクリック。拡張子に応じて編集モードが切り替わります |
| タブの並べ替え | ドラッグ＆ドロップ、またはタブにフォーカスして `Alt+Shift+←/→` |
| タブを閉じる／開き直す | `Alt+W`、タブの `×`、中クリック／`Alt+Shift+T` |
| 次／前のタブ | `Ctrl+Tab` / `Ctrl+Shift+Tab`（ブラウザが優先する場合は `Alt+PageDown` / `Alt+PageUp`） |
| 検索／置換 | `Ctrl+F` / `Ctrl+H`。`Enter` で次、`Shift+Enter` で前、`F3` / `Shift+F3` |
| すべてのタブから検索 | `Ctrl+Shift+F`、または検索パネルの「全タブ検索」 |
| 指定行へ移動 | `Ctrl+G`（`行:列` 形式も可） |
| 折り返し／Markdown プレビュー | `Alt+Z` / `Alt+P` |
| 画面分割（1〜4 分割） | 「表示」メニューの「画面分割」、またはツールバーの「分割 1 2 3 4」 |
| 差分比較（2 つのペインの内容を比較し、結果を 3 つ目のペインに表示） | 「表示」→「差分比較…」。前の差分 / 次の差分は `Shift+F8` / `F8`、「比較終了」で通常の編集に戻る |
| ペインの切り替え | ペインをクリック、`Alt+1`〜`Alt+4` |
| タブを別のペインに表示 | タブをペインへドラッグ＆ドロップ、またはペイン見出しの `▾`（空のペインでは「タブを選択…」） |

ショートカットの一覧は「ヘルプ」→「キーボードショートカット」で確認できます。
`Ctrl+N`・`Ctrl+Tab`・`Ctrl+W` などはブラウザの操作が優先され Web ページから上書きできないため、Alt 系の代替キーを用意しています。

### 保存状態と操作対象

- 編集領域の上に「操作対象：ペイン番号 — ファイル名」を表示します。検索・置換・書き出しはこのタブが対象です。「全タブ検索」「全タブをすべて置換」は全タブが対象です。
- 同じ行の「ファイル未書き出し ●」は、PC への書き出しが必要な変更を示します。「ファイル変更なし」は最後の読み込み・書き出し以降に変更がない状態です（新規の空タブも含みます）。
- 下部の「自動保存済み」はブラウザ内への保存状態です。自動保存されても「ファイル未書き出し ●」とタブの `●` は残り、ファイルへの書き出しで解消します。
- 検索パネルの「このタブ内」と全タブ操作のボタン名で対象範囲を区別します。ペインやタブを切り替えると操作対象も切り替わります。
- 分割時のタブ一覧には、表示先のペイン番号または「未表示」を表示します。差分結果のペインでは読み取り専用であることを表示し、ファイルの状態は表示しません。

### 全タブ検索結果の更新

全タブ検索結果は検索実行時点の一覧です。本文・検索条件（検索語、大文字小文字、単語単位、正規表現）・タブの追加／削除／名前変更・バックアップ復元で内容が変わると、「検索結果が古くなっています」と表示します。検索時の語句と一覧を残し、古い結果からの移動は止めます。

結果一覧の「再検索」で、現在の検索条件と全タブの本文から一覧を更新してください。検索語が空、または正規表現が不正な間は更新できません。置換後の文字列の入力やペイン／タブの切り替えだけでは古い扱いになりません。編集中に全タブ検索を自動実行することはありません（全タブ置換後は従来どおり結果を更新します）。

### 全タブ置換のプレビュー（未リリース）

「全タブをすべて置換」で、確定前にタブ番号・ファイル名・置換前の行列位置・行の抜粋と変更前後を確認できます。初期状態では一致する全タブを選択しています。タブごとのチェックで対象を選択・除外でき、選択したタブ数と置換件数、プレビューが更新されます。本文は「置換する」で確定するまで変わらず、キャンセルや Esc でも変更しません。タブ番号は検索時のタブ一覧の順番で、同名のファイルも区別できます。

候補は20タブずつページで表示し、別ページも選択できます。選択はページ間で保持され、「全タブを選択」「全タブを解除」は全ページに作用します。対象なしの間は「置換する」を無効化します。プレビューは表示中の選択タブごとに先頭5件、変更前後各200文字までです。省略件数と上限を明記し、別ページや省略分も含む、選択したタブの全件だけを置換します。正規表現の参照や改行は実際に挿入する文字列で表示し、挿入前／削除後の空文字列は「（空文字）」と表示します。

選択外のタブの本文は変更せず、Undo/Redo の履歴も維持します。確認後に本文・検索条件・置換文字列・タブ構成が変わると、古い確認内容のまま実行せず、キャンセルしてプレビューを作り直すよう案内します。置換後は各タブで `Ctrl+Z`／`Ctrl+Y` により Undo／Redo できます。

### 画面分割（マルチペイン）

複数のファイルを左右に並べて、比較・参照しながら編集できます。

- 2・3・4 分割では、画面を縦の区切り線で左右に等幅で分割します（画面サイズを変えても等幅を保ちます）。画面が狭い場合は各ペインを一定幅以下に縮めず、編集領域を横スクロールします。
- タブバーは 1 つで、すべてのペインで共有します。タブをクリックするとアクティブなペイン（見出しが強調表示されたペイン）に表示します。別のペインに表示中のタブをクリックすると、そのペインへ移動します。タブの番号表示（`1`〜`4`）は表示先のペインです。
- 1 つのタブは 1 つのペインにだけ表示します。別のペインへドラッグすると、元のペインからは外れます。
- 分割した直後は、表示中のタブに続けて未表示のタブを順に各ペインへ割り当てます。タブが足りないペインは空になり、タブの選び方を案内します。
- 分割数を減らしても、閉じたペインに表示していたタブは削除されません（編集内容・Undo 履歴もそのまま残り、タブバーから再び表示できます）。
- 検索・置換・行ジャンプ・書き出し・ステータスバー・Markdown プレビューはアクティブなペインのタブが対象です。「全タブ検索」「全タブをすべて置換」はすべてのタブが対象です。
- 分割数・各ペインのタブ・アクティブなペインはブラウザ内に保存され、再読み込み後に復元されます。

### 差分比較

2 つのペインに表示しているタブの内容を比較し、差分だけを 3 つ目のペインに表示します（新しいパネルや別ウィンドウは設けず、既存の分割ペインを使います）。

1. 比較したい 2 つのファイルを、それぞれタブとして開いておきます。
2. 「表示」→「差分比較…」を開き、次の 3 つを選んで「比較する」を押します。ペイン番号と、そのペインで表示中のタブ名が一覧に出ます。
   - **比較元（変更前）のペイン**・**比較先（変更後）のペイン**: それぞれのペインで表示中のタブの内容を比較します（タブを選び直す必要はありません。空のペインは指定できません）。
   - **差分結果を表示するペイン**: 空のペインでも、既存のタブを表示しているペインでもかまいません（その場合、タブは比較を終了するまで一時的に非表示になります）。
   - 3 つとも別のペインにする必要があります。
3. ペインが 3 つ未満のときは、自動で 3 ペインに拡張します（1 ペインのときは、現在のタブが比較元、別の既存タブが比較先になります）。キャンセルした場合は、ペイン配置を変更しません。
   **比較設定の補助**：「比較元と比較先を入れ替え」で2つの選択を交換できます（結果表示の指定は維持）。重複したペインや空の比較元・比較先を選ぶと、その場で理由と該当欄を示し、修正するまで「比較する」は無効になります。キャンセルしても現在の配置は変わりません。表示メニューの見出しは「差分比較（比較元・比較先・結果）」に統一しています。

4. 差分結果は、Git の diff に近い形式で、差分のある箇所だけを表示します（読み取り専用）。

   ```
   @@ -2,1 +2,1 @@
   - timeout=30
   + timeout=60

   @@ -4,1 +4,2 @@
   - debug=false
   + debug=true
   + cache=true
   ```

   削除行は赤、追加行は緑の背景で、変更行は変更前（`-`）に続けて変更後（`+`）を表示し、行内の異なる文字も強調します。左側のガターに比較元・比較先の行番号を表示します。差分がなければ「差分はありません」と表示します。
5. 画面上部のバーに差分の件数（追加・削除・変更）と現在位置を表示します。「前の差分」「次の差分」（`Shift+F8` / `F8`）で移動すると、選択中の差分を結果で強調し、比較元・比較先の対応する位置を表示します。結果の差分（行や行番号）をクリックしても、同じようにその差分を選択して対応位置を表示できます。「比較対象…」で 3 つのペインの指定を変更できます。
6. 「比較終了」で、結果表示を閉じ、比較開始前のペイン数・タブ配置・アクティブなペインに戻します（元々空だったペインは空のまま、結果表示のために非表示にしたタブは元のペインに戻ります）。

- 比較元・比較先のペインでは、通常どおり編集できます。編集すると差分結果が少し遅れて自動更新されます。Undo/Redo の履歴は保持され、比較を終了しても編集内容は残ります。比較のために本文やタブを複製・変更することはありません。
- 差分結果は編集用のタブではなく、ブラウザ内保存・バックアップには含まれません。比較の状態も保存されないため、再読み込みすると比較は解除された状態で開きます（その場合、結果表示のために非表示にしていたタブは元のペインに表示されます）。
- 比較中のタブを閉じる、比較元・比較先・結果表示のペインに別のタブを表示する、バックアップを復元する、など比較を続けられない操作をすると、比較を自動で終了します（編集内容は失われません）。
- 片方の変更をもう片方へ反映するマージ機能はありません。差分の確認用です。
- 非常に大きく異なる 2 つのファイルでは、比較に時間がかかる場合があります。その場合は行内の強調などが粗くなることがあります。

### ブラウザ内保存とファイル書き出しの違い

- **ブラウザ内保存**（ツールバー「ブラウザに保存」・`Ctrl+S`）: このブラウザの localStorage に保存します。再読み込みやブラウザ再起動後も復元されますが、PC 上のファイルにはなりません。ブラウザのデータ削除で消えます。
- **ファイルに書き出し**（ツールバー「ファイルに書き出し」・`Ctrl+Shift+S`）: 現在のタブを PC へダウンロードします。タブの `●` は「ファイルに書き出していない変更がある」ことを示します。
- **バックアップ**（「ファイル」メニュー）: 全タブと設定を 1 つの JSON ファイルとして書き出し、別の PC・ブラウザで復元できます。復元時は内容を検証し、既存データを置き換える前に確認します。

### 未書き出しタブの一括書き出し（未リリース）

「ファイル」→「未書き出しタブをまとめて書き出し…」から、対象を選んで1つの ZIP として取得できます。候補は未書き出しのタブだけで、20タブずつ表示します。全選択・全解除は全ページに作用し、選択なしでは実行できません。

ZIP には通常のテキストファイルを UTF-8 で格納し、各タブの改行コードと BOM を反映します。Shift_JIS で読み込んだタブも出力は UTF-8 です。同名・大文字小文字だけが異なる名前・使用できない文字・長い名前は、ZIP 内で重複しない名前へ調整します。タブ番号と出力名を一覧で確認でき、元のタブ名は変えません。

ダウンロード開始だけでは未書き出し表示を解除しません。ZIP を保存できたことを確認して、次の画面で「保存を確認した」を選ぶと、出力後に本文や書き出し設定が変わっていないタブだけを書き出し済みにします。保存を中止・保留した場合は「未書き出しのまま閉じる」または Esc で閉じてください。生成やダウンロード開始の失敗時にも状態は解除しません。

本文と Undo/Redo 履歴は維持します。この ZIP は、全タブ・設定を復元するバックアップ JSON とは別の機能です。ZIP の生成はブラウザ内で行い、外部 API や CDN へアクセスしません。

## 主要機能

- **タブ**: 複数タブ、切り替え、名前変更、削除（誤操作防止の確認・閉じたタブの再オープン）、ドラッグ＆ドロップでの並べ替え、横スクロール、タブ一覧
- **差分比較**: 比較元・比較先・結果表示の 3 つのペインを指定し、差分のある箇所だけを Git 風の形式で結果ペインに表示（追加・削除・変更・行内の異なる文字の強調、比較元・比較先の行番号）、差分の件数表示、前後の差分への移動と対応位置の表示、比較中の編集への追従
- **画面分割**: 1〜4 分割（左右に等幅）、ペインごとに別のタブを表示・編集・スクロール、ドラッグ＆ドロップでのタブの移動、分割状態の保存・復元
- **タブごとに独立**: 本文・Undo/Redo 履歴・カーソル位置・スクロール位置（履歴はタブを切り替えても維持。再読み込み後は本文・カーソル・スクロール位置を復元）
- **編集**: 行番号、折り返し、複数カーソル（`Ctrl+クリック`、`Alt+ドラッグ`、`Ctrl+D`）、自動インデント、タブ幅・インデント文字の変更、行の複製・移動・削除、括弧の対応強調、現在行の強調、コード折りたたみ、空白・タブ・改行コードの可視化
- **検索・置換**: 大文字小文字の区別、単語単位、正規表現（`$1`・`$&` での参照、`\n`・`\t`）、件数表示、すべて置換（Undo 可）、全タブ横断検索と結果からの移動、全タブ一括置換
- **構文ハイライト**: Plain Text / Markdown / JSON / JavaScript / TypeScript / HTML / CSS / XML。拡張子から自動判定し、ステータスバーや「言語」メニューから手動で切り替え可能
- **Markdown プレビュー**: 編集内容に追従して表示。DOMPurify による無害化と CSP によりスクリプトは実行されません
- **ファイル入出力**: 複数ファイルの一括読み込み、ドラッグ＆ドロップ、UTF-8（BOM の有無を維持）、Shift_JIS の読み込み、改行コード（CRLF / LF / CR）の維持と変更
- **保存の安全性**: デバウンス付き自動保存（変更のあったタブのみ書き込み）、容量超過・保存失敗の通知（編集内容は破棄しない）、別のブラウザタブとの保存競合の検知（無警告で上書きしない）、破損データの保護
- **UI**: ライト／ダークテーマ、文字サイズ変更、設定の永続化、日本語 UI、キーボード操作、狭い画面への対応

## 開発

Node.js 20.19 以上（22 推奨）が必要です。

```bash
npm ci              # 依存パッケージのインストール
npm run dev         # 開発サーバー（http://localhost:5173/）
npm run typecheck   # 型チェック
npm test            # 単体テスト（Vitest + jsdom）
npm run build       # 型チェック + 本番ビルド（dist/ に出力）
npm run preview     # ビルド結果の確認
npm run test:e2e    # E2E テスト（Playwright。事前に npm run build が必要）
```

E2E テストを初めて実行する場合は `npx playwright install chromium` でブラウザを取得してください。
E2E テストはビルド結果を `/editor/` 配下で配信し、GitHub Pages のサブパス配備を再現して実行します。

### ディレクトリ構成

```
src/
  core/      タブモデル・画面分割モデル・差分計算・検索・改行コード・文字コード・バックアップ・Markdown 変換（DOM 非依存）
  editor/    CodeMirror の構成、タブごとの EditorState 管理、言語の遅延読み込み、テーマ
  storage/   保存処理（StorageBackend インターフェース、localStorage 実装、自動保存制御、スキーマ）
  files/     ファイルの読み込み・書き出し
  ui/        メニュー・タブバー・編集ペイン・ステータスバー・検索パネル・ダイアログ等の UI 部品
  app/       各部品をつなぐアプリ本体、コマンド、メニュー定義、ショートカット
tests/
  unit/      単体テスト
  e2e/       E2E テスト
```

保存処理は `StorageBackend` インターフェース（`src/storage/backend.ts`）で抽象化しており、IndexedDB 等の実装へ差し替えられます。
保存データにはスキーマバージョンを持たせており、形式を変更する場合は `src/storage/schema.ts` の `SCHEMA_VERSION` と `migrate` を更新します（v0.2.0 でスキーマ v2 に更新し、v1 のデータは読み込み時に自動で移行します）。

差分比較は、差分の計算と統一差分形式への整形（`src/core/diff.ts`）、比較元・比較先の強調表示を各タブの EditorState に持たせる拡張（`src/editor/diffMarks.ts`）、結果表示の読み取り専用ビューの拡張（`src/editor/diffResult.ts`）、比較の進行とペイン配置の復元（`src/app/diffController.ts`）に分かれています。結果表示は `EditorManager` の一時的なビュー（タブではない読み取り専用の EditorState）として表示し、ペインのタブの本文・Undo 履歴は退避して、終了後にそのまま復元します。

画面分割は、どのペインにどのタブを表示するかを `PaneLayout`（`src/core/paneLayout.ts`）が、ペインごとの CodeMirror の表示を `EditorManager`（`src/editor/editorManager.ts`）が担当します。タブの一覧・順序は従来どおり `TabStore` が管理します。

## 配備

GitHub Actions ではアプリのテスト・ビルドに Node.js 22 を使用します。CI・Release のアーティファクト転送と Pages のアクションは Node.js 24 対応版を使用します。アクション自身の実行ランタイムと、`actions/setup-node` で選択するアプリの Node.js バージョンは別の設定です。

`npm run build` で `dist/` に静的ファイル一式が出力されます。アセットは相対パスで参照するため、任意のサブパスに配置できます。

### GitHub Pages

`main` ブランチへの push（PR のマージ）で `.github/workflows/deploy.yml` が実行され、テスト・ビルド後に GitHub Pages へ配備されます。
初回のみ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。
公開 URL は `https://<ユーザー名>.github.io/<リポジトリ名>/` です。

PR では `.github/workflows/ci.yml` により型チェック・単体テスト・ビルド・E2E テストが実行されます。

### リリースビルド（配布用 ZIP）

ローカルでビルドしなくても、GitHub Actions で配布用 ZIP を作成し、GitHub Releases から取得できます。

v0.4.0 は UX-01・02・03・06・09・10 を収録して公開済みです。未リリースの機能は今後の公開対象として別に扱います。ドキュメントの整備やローカルのビルド成功は、Release の公開完了を意味しません。

公開準備の検証は、Release ワークフローと同じ Node.js 22 で次を実行します。最後の2つのスクリプトはローカルの ZIP 作成と取得確認を行います。

```bash
npm ci
npm run check
npm run test:release
./scripts/release/changelog-section.sh v0.4.0 CHANGELOG.md > /tmp/editor-v0.4.0-notes.md
./scripts/release/package.sh v0.4.0 dist /tmp/editor-v0.4.0.zip
./scripts/release/smoke-test.sh /tmp/editor-v0.4.0.zip
```

加えて、既存の Playwright E2E（上記「開発」の手順）を実行し、保存状態・全タブ検索の更新・3ペイン比較の動作を確認します。

公開する変更とバージョンの更新を main にマージしてから、ワークフローを実行します。

1. `package.json` の `version` と `CHANGELOG.md` の「`## v0.4.0`」の節を用意して `main` にマージする
2. GitHub の **Actions → Release → Run workflow** を開き、ブランチは `main` のまま、`version` に `v0.4.0` の形式で入力して実行する
3. 完了後、**Releases** の「Web Text Editor v0.4.0」から `editor-v0.4.0.zip` をダウンロードする

- 型チェック・単体テスト・本番ビルドと、ZIP を静的 Web サーバーのサブパスに展開した動作確認がすべて成功した場合だけ、Release を作成します。リリースノートは `CHANGELOG.md` の該当バージョンの節から作成します。
- タグ（`v0.4.0`）がなければ、実行時点の `main` の最新コミットに作成します。タグがあれば、そのタグのコミットをビルドします（既存のタグは移動しません）。
- 同じバージョンで再実行すると、同じタグのコミットからビルドし直し、Release の ZIP・タイトル・本文を差し替えます。新しい ZIP を一時名でアップロードし、旧 ZIP を退避名に変えてから新しい ZIP を正式名にし、最後に旧 ZIP を削除します。途中で失敗した場合は旧 ZIP を正式名に戻します（戻せない場合も削除せず、`editor-vX.Y.Z.previous-….zip` として残し、エラーで通知します。再実行すると差し替えを完了します）。
- リリース用のスクリプトは `scripts/release/`、そのテストは `npm run test:release` です。

### ローカルで配布版を確認する

Releases の ZIP を展開して `index.html` をダブルクリック（`file://`）で開くと、ブラウザの CORS 制限により JavaScript・CSS を読み込めず、画面が表示されません。
Windows では、リポジトリの `scripts/serve-editor.ps1` で簡易 HTTP サーバーを起動して確認できます（Windows PowerShell 5.1 で動作し、Node.js・Python・IIS は不要です）。

1. [Releases](https://github.com/YanTKYS/editor/releases) から `editor-vX.Y.Z.zip` をダウンロードし、任意のフォルダー（例: `C:\work\editor`）に展開する（直下に `index.html` と `assets/` が並びます）
2. `scripts/serve-editor.ps1` をダウンロードするかリポジトリを取得し、PowerShell で展開先のフォルダーを指定して実行する

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\scripts\serve-editor.ps1 -Folder C:\work\editor
   ```

   `-Port 9000` のようにポート番号を変更できます（既定は 8765）。`-Folder` を省略すると、現在のフォルダーを配信します。
3. ブラウザで <http://localhost:8765/> を開く
4. 確認が終わったら、PowerShell で `Ctrl+C` を押して終了する

サーバーは `127.0.0.1` のみで待ち受けるため、同じネットワークの他の PC からはアクセスできません。確認用の簡易サーバーであり、配布用 ZIP には同梱しません。

### IIS 等の静的 Web サーバー

`dist/` の中身、または Releases の `editor-vX.Y.Z.zip` を展開した中身（直下に `index.html` と `assets/`）を、任意のディレクトリ（例: `C:\inetpub\wwwroot\editor\`）にコピーするだけで動作します。サーバー側の設定やリライトは不要です。

## 注意事項

- ブラウザ内保存の容量はブラウザごとに異なります（一般に 500 万文字程度）。同じオリジン（例: `○○.github.io`）上の他のアプリと容量を共有します。容量が不足した場合は画面上部に通知されますので、不要なタブを閉じるか、ファイル・バックアップに書き出してください。
- 保存データのキーは `webTextEditor:` で始まります。
- 書き出しは常に UTF-8 で行います（Shift_JIS で読み込んだファイルも UTF-8 で書き出されます）。
- 同じエディタを複数のブラウザタブで開いた場合は通知が表示されます。一方で保存されると、もう一方では自動保存を停止し、上書きするか読み込み直すかを選択できます。
- v0.1.0 から更新した場合、ブラウザ内の保存データは初回読み込み時に自動で新しい形式（スキーマ v2）へ移行されます（タブ・本文・設定はそのまま引き継がれ、1 画面の状態で開きます）。移行後のデータは v0.1.0 では読み込めません（上書きを防ぐため保存を停止します）。
- バックアップ JSON の形式は v0.1.0 と互換です。v0.1.0 のバックアップは v0.2.0 で復元でき（現在の分割数でタブを順に割り当てます）、v0.2.0 のバックアップも v0.1.0 で復元できます（画面分割の情報は無視されます）。
- `Alt+1`〜`Alt+4` は、環境によってはブラウザのタブ切り替えに使われ、Web ページでは受け取れない場合があります。その場合はペインをクリックするか、「表示」メニューから移動してください。
